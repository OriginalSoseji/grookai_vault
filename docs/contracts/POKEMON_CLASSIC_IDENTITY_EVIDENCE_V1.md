# Pokemon Classic identity evidence V1

This is a bounded source adapter and accepted identity-evidence candidate for all
102 English Trading Card Game Classic cards. It implements the existing
`ENGLISH_MASTER_INDEX_COMPLETION_V1` and `MASTER_INDEX_GOVERNANCE_CONTRACT_V1`
identity standards. It does not relax their finish, guarded-staging or publication
gates, and does not authorize database writes.

The adapter verifies original snapshot SHA-256, successful acquisition, source
host and retrieval time before parsing. It independently parses PkmnCards' three
deck pages and Bulbapedia's explicit English section. Named deck headings bind
the English tables; position alone cannot bind a deck. Every deck requires exactly
001/034 through 034/034 and 60 physical cards. Japanese tables, nonfinal product
images and market buckets supply no finish facts.

The exact name comparison only folds accents/punctuation, expands the six Basic
Energy type symbols, and recognizes the explicitly present Boss's Orders
[Giovanni] display alias. Raw names remain in every evidence record. It does not
remove arbitrary parenthetical, retailer, staff or other variant qualifiers.
Each fact requires independent PkmnCards and Bulbapedia agreement. The existing
Master source classifier must produce exactly102 two-authority card identities,
zero printings and zero conflicts before the whole package can be emitted.

Printed CLV/CLC/CLB are preserved separately from proposed canonical container
codes `classic-clv`, `classic-clc`, `classic-clb`. Production has a global unique
set-code index and MTG already owns `clb`. Qualification therefore requires a
fresh complete all-game set inventory and rejects occupied proposed codes.
These are proposals, not aliases or permission to create sets. Canonical execution
must recheck every code, source relationship, parent and dependency transactionally.

The report honestly identifies automated source qualification, with no human
signature. All three sets remain `card_identity_complete_finish_incomplete`.
The204 source records may feed guarded Master staging; they do not silently
replace the active Master or claim complete sets. Exact English finish evidence,
three locked printing manifests, non-regression/completion outputs, and a new
governed canonical/mapping executor remain required. Raw ingress and canonical
admission remain distinct phases.

Run the offline CLI with `--source-dir=<preserved handoff>`,
`--namespace=<fresh read-only snapshot>` and `--out-dir=<new directory>`.
It acquires no data and has no DB connection or apply mode. It preserves four
compressed source snapshots, the204-row fixture, and the102-card qualification
package, with immutable output files. The source fixture directory can be read by
the existing `collectHumanFixtureEvidence` adapter; no alternate Master classifier
or new review-signature authority is introduced.
