# TCGTracking exact condition coverage V4

Status: bounded read-only implementation under qualification. Existing V2/V3
authentication, source, freshness, exact amount, currency, cache and valuation
boundaries remain binding. This adds no database or Market write authority.

The registry contains exactly43 existing generic Play! Pokémon stamped parents
and their separately reviewed Normal child proposals. Original official black
standard-set markers and an independent checklist prove those physical Normal
facts. Existing source-backed JustTCG parent mappings and preserved raw card
records provide43 unique explicit TCGplayer product IDs. Each active category3,
group22880 product independently agrees on exact name and printed Number.
The registry binds canonical/identity UUIDs, original mapping/candidate metadata,
source product/coordinates and the reviewed printing program/manifest hashes.
Raw provider payloads, prices and original PDF/wiki bytes stay outside Git.

This path becomes eligible only after the exact approved printing actually exists:
nonprovisional Normal, exact GV-ID/provenance/creator, unchanged parent fields,
one original active identity, one Normal sibling, and the exact high-confidence,
visible verified review with matching program, manifest and raw receipt pins.
Every active review must remain visible and verified. A proposed UUID, generic
stamp, supplier finish token or another card's fact never creates authority.

Require exactly one original active JustTCG mapping and no persistent TCGplayer
assertion on that parent or child. Revalidate current active source product,
category/group, exact name and sole Number. Reject competing JustTCG owners,
TCGplayer parent owners or exact-printing product owners. Inactive TCGplayer
assertions also withhold this new lane; an invalidated mapping cannot be revived
through a source crosswalk. If a persistent
TCGplayer assertion exists, the earlier V1/V3 readers decide it; this lane cannot
bypass their conflict or ineligibility result. Legacy stamp variants, other
parents, foil patterns and every UUID outside this exact registry stay outside
V4. Source/identity/review drift fails closed without modifying the record.

The crosswalk selects only product + physical finish + English language for the
existing reference reader. It does not insert external mappings, change Master
truth, fill a Market tile, publish an amount or change Vault totals. Existing
mapping executors and their base-variant/approval gates remain unchanged. Source
SKU amounts are exact and condition-specific; absent, stale or ambiguous SKUs
remain unavailable. No percentage, condition substitution or price blending is
permitted. Currency remains unverified, labeled USD assumed, confidence medium.

The existing authenticated API and CONDITION_PRICE_READ_MODEL_V1 DTO remain
compatible with installed clients. Every request revalidates identity authority
before consulting the bounded shared source cache. Require normal hooks, hosted
review and deployed authenticated acceptance. Record source/mock proof separately
from actual production printing apply and real application verification. The
separate49-printing package still needs its original exact founder approval,
actual production rollback and durable readback; this reader grants none.
