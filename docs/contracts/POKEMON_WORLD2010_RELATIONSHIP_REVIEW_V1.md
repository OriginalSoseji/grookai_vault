# Pokemon World2010 existing relationship review V1

Status: new automated source qualification; no executable production package.

The standing repair-owner instruction authorizes this automated policy. Review
attribution is `automated_agent:codex_pokemon_relationship_repair`, with the actual
review time and a null human signature. It does not reuse historical approvals.

The fixed universe is all109 retained TCGCSV products from the four2010 World
Championship decks in category3/group2282. The qualifier independently reparses
four hash-bound original deck checklists, including each60-card quantity, year,
player signature and exact deck identity. It does not consume the earlier92-row
worklist as authority. Repeated individual wiki links bind one card tuple; greedy
multi-link parsing cannot concatenate an origin set. Unnumbered Energy stays held.

Every accepted relationship requires exact source year/signature, deck set,
normalized printed name, raw canonical number, original-set provenance, printed
denominator, replica variant and deck modifier. Normalization retains letters and
numbers in SP/LV.X/retailer qualifiers. A redundant parenthetical number is removed
only when equal to the source's printed coordinate. No cross-set name suggestion
can substitute for these fields. The existing parent UUID and GV-ID are retained.

The review contains92 exact existing-parent relationships and17 explicit holds.
It preserves all109 parents and100 existing children/reviews. Those prior printing
reviews are data to preserve, not new finish authority. It neither writes children
nor relabels their historical raw provenance. All nine existing TCGCSV discovery
and raw IDs must match exact original payloads;83 candidates still need separately
governed raw ingress. Parent mapping identifiers remain `tcgcsv:2282:<product>`;
discovery upstream identifiers remain `tcgcsv:3:<product>`. No TCGPlayer or TCGdex
mapping is fabricated. Any changed scope, additional mapping/identity, duplicate,
source contradiction or formerly held candidate stops the whole fixed review.

`scripts/audits/pokemon_world2010_relationship_review_v1.mjs` accepts exactly
`--snapshot`, `--receipt`, `--originals-dir`, and a NEW `--out-dir`. It is entirely
offline. The snapshot must match the independently read-back, verified-TLS,
read-only observation receipt and canonical sanity floors. Its observed time is
reported honestly; offline qualification cannot establish current live state.

Outputs bind the actual source bytes, every accepted live parent/product,
retained lineage, child/review, full preserved arrays and all holds. Production
writes and repaired relationships remain zero. Source-qualified relationship
review is not a canonical identity insertion, mapping executor or apply permit.
