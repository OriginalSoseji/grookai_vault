# English Pokemon Base Printing Release V1

Status: Active

Date: 2026-11-15

## Purpose

Admit the exact base physical printing for every parent in a newly staged
English Pokemon set without allowing pricing feeds or provider finish buckets to
manufacture additional printings. This lane begins only after the complete
parent set is canonical and hidden.

## Authority

Every release requires a checked-in `PRINTING_COMPLETENESS_GATE_V1` manifest
that binds:

- the complete canonical parent scope;
- an official or governed checklist projection with exact collector numbers;
- one verified base finish and governed printing GV-ID per parent;
- exact parent, printing, and finish counts;
- explicit protected, forbidden, suppressed, and unresolved facts;
- a projection-bound review record and immutable source hashes.

Price observations, provider subtype names, or variant flags may corroborate a
base finish or preserve an unresolved lead. They are never printing authority.
Any Reverse Holo or specialty finish absent from the authoritative checklist
remains outside the base release until separately proven.

## Write Envelope

After a same-fingerprint serializable rollback rehearsal and exact founder
approval, one transaction may:

- insert one preserved `raw_imports` evidence receipt;
- insert the exact missing base `card_printings` rows;
- insert one active, verified truth review per inserted printing.

The transaction may not update or delete an existing row. It may not write
parents, identities, mappings, prices, publications, images, Storage, Vault,
ownership, customer data, or set visibility.

`card_printing_truth_reviews.public_visibility = visible` means that the child
fact is eligible once catalog visibility is separately activated. It does not
activate the set or make the child appear through the public printing-options
RPC while the set is hidden or its parent is suppressed. The set release
control must remain `hidden`, and every parent suppression marker must remain
unchanged.

## Execution Gates

The planner and the transaction must each prove:

- canonical project routing and minimum environment counts;
- exact set UUID, code, parent count, and hidden release control;
- all parent identities equal the frozen manifest;
- exact manifest fingerprint and source artifact hashes;
- exact finish counts and no duplicate parent/finish or printing GV-ID;
- zero candidate UUID, GV-ID, review-ID, or raw-receipt collisions;
- zero existing set children for a fresh-set release;
- zero active mappings and zero current publications for the target parents;
- all protected facts present, no forbidden or suppressed fact in the plan;
- no parent, release-control, mapping, publication, Vault, or image mutation;
- exact in-transaction readback followed by rollback absence;
- an independent durable readback after any approved commit.

Commit acknowledgement uncertainty stops the release. Never retry blindly.
Read the exact candidate IDs through a new connection before any recovery.

The checked-in real-apply runner must be part of the dry-run code fingerprint.
It accepts only the exact merged source SHA, package fingerprint, rollback
artifact, and founder approval text. It writes its durable receipt outside the
worktree, performs one serializable insert-only transaction, and treats an
independent exact readback as the only authority after any uncertain commit.

## Delta Reign V1 Scope

The first package is `me06` / Delta Reign, set UUID
`c72b4744-db4d-565f-9914-e28a2b244f5c`. The official Pokemon checklist proves
141 base printings: 83 Normal and 58 Holo. The 87 current TCGPlayer Reverse
Holo price subtypes remain review leads and are not part of this release.

The set stays hidden after this stage. Exact TCGPlayer parent mappings, governed
pricing publication, image readiness, and public set activation are later,
separately approved releases.
