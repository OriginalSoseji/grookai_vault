# MTG public additive rehearsal V1

This separately versioned qualification path tests adding reviewed, released MTG
prints while MTG remains public. It does not modify the frozen V1 ingestion
envelope, hidden-only writer, release control, or supervisor completeness rules.

The checked-in Reality Fracture truth manifest binds exact reviewed payloads,
source bulk, parent and finish counts, protected printing facts, and held future
identities. Price links never create printings. Missing or nonpositive source
prices remain unavailable. Released-only coverage is not full-source completeness.

The executor is local and rollback-only. It requires the attested retained schema
428 lab on loopback port 55000, its private subnet, disabled background workers,
and a serializable transaction. There is no production connection, CLI apply mode,
commit path, migration, runtime deployment, or production authorization.

The harness may temporarily simulate the public release control inside its outer
test transaction. That fixture preparation precedes the protected baseline and is
rolled back with everything else. The import itself requires public visibility
and cannot change it. Existing labs are never reset, truncated, or reseeded.

Each payload first enters the established service-only immutable MTG staging
tables and must read back exactly. Only then may its six canonical insert tables
be exercised. All native rows outside planned additions, release controls, saved
copies, pricing, schema ledger, and table security must remain exact. Independent
post-rollback readback must restore the complete original state.

Local rehearsal uses negative mapping surrogate IDs without advancing a sequence.
This proves row content, constraints, staging and visibility, but does not qualify
the production sequence-allocation/commit path. Production work still requires a
separately qualified executor, current completed source, full production baseline,
new immutable release manifest, durable rollback/commit evidence, and versioned
supervisor coverage that explicitly accounts for future-card holds. No approval
sentence is invented by the rehearsal and no old authority is reused for new rows.
