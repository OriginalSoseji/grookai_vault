# Pokemon Classic finish evidence V1

This bounded offline adapter qualifies an additive evidence candidate for the
102 standard English Classic deck cards. It implements the existing Master
two-independent-source rule; it does not authorize database writes, activate
the Master, or assert whole-product completeness.

Each exact deck/number/name requires an explicit Holo Variant cell on the
preserved ThePriceDex human-readable checklist AND an independently acquired,
visually reviewed final English physical-card photograph. The checklist's
embedded data checks English language, physical scope and displayed row parity.
It is the same source, never an additional vote. Prices, rarity, linked market
IDs and TCGCSV metadata supply no finish facts.

The photo review is explicitly an automated-agent observation, performed by
Codex under the standing relationship-repair task. It is not a human signature
or a claim that a deterministic parser understands pixels. Every observation
binds the original image bytes and URL, exact printed English identity,
denominator, visible holographic surface, review time and absence of an observed
conflict. Acquiring an image or copying an old review is insufficient. Original
source bytes must be available and hash-match during qualification and independent
output readback. An unclear photo blocks the whole package pending new evidence.

The allowed physical sources are TCG Mart London's 101 original front photos
and the independently acquired C2GCollect eBay photograph for CLC027 Super Rod.
The latter's exact public image link was read through the web tool; original
listing HTML acquisition returned403 and remains preserved as failed evidence.
The image itself returned200 over verified TLS and was visually inspected.
The original gallery's404 is retained, never relabeled successful.

The candidate uses existing canonical `holo`, matching each explicit checklist
label and observed physical foil. Patterned foil and diagonal rainbow foil remain
separate raw observations. This does not map stars to Cosmos, invent a named
Classic finish, assert Normal/Reverse absence, or infer a finish from membership
in the deck. Japanese and prerelease pictures do not contribute.

All102 exact facts must qualify together. Missing/duplicate coordinates,
byte drift, failed acquisition, wrong language, name/deck conflicts, copied
photographs, unreviewed surfaces, or new unclassified variants block output.
Three proposed standard-deck profiles each protect34 exact Holo facts. They
are evidence profiles, not canonical manifests with assigned UUIDs or GV-IDs.

ThePriceDex's extra CLV017 Lugia ex Jumbo row is retained as
`outside_standard_deck_scope_review_required`, with `resolved:false`. It is
neither a standard-card finish nor evidence to create a Jumbo identity. The
standard deck scope can qualify while this separate size claim remains held;
the package must never report whole-product completeness or hide that claim.

The CLI replays the existing102 identity package from its original snapshots,
then qualifies the finish candidate and copies all evidence into a new immutable
directory. It independently rereads and replays the copied originals. No database,
network, active-index promotion or apply mode exists. Source fixture acceptance,
guarded Master integration, canonical set/parent/printing/mapping admission,
isolated SQL proof, normal checks/hooks and frozen apply/readback remain separate.
