- The installed APK is signed with the Android debug certificate SHA-256
  `e9575fdd80e4bc1b4e5a80e3638c76f963ae2618db4f71f95d5a0022bc7089c2`.
- The available CI release candidate 551 is older than the installed app, so the
  preflight correctly rejects it before considering an update.

  writes its public certificate report to stderr. The workflow captures both
  output streams before extracting the fingerprint.
- Earlier CI release artifacts use a different distribution signer. They must
  not be installed over this debug-signed app; no uninstall or data reset is
  permitted to force the update.
